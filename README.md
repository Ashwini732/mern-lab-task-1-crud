# CRUD Operations Using Express.js and REST API

## Project Description
A simple web application that performs CRUD (Create, Read, Update, and Delete) operations on an array of items using HTML, CSS, JavaScript, Express.js, and REST APIs.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- REST API

## Features
- Add new items
- View all items
- Update existing items
- Delete items

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm start`.
4. Open `http://localhost:3000` in your browser.
