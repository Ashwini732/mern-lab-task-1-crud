# MERN Lab Task 1 – CRUD Operations on an Array Using REST API

## 📌 Project Description

This project is a simple web application developed to perform **CRUD (Create, Read, Update, and Delete) operations** on an array of items using HTML, CSS, JavaScript, Express.js, and REST APIs.

The application allows users to add new items, view the list of items, edit existing item details, and delete items through an interactive web interface. The Express.js server handles API requests and manages the items stored in an in-memory array.

## ✨ Features

- **Create:** Add new items by entering their name and price.
- **Read:** Display all available items in a table.
- **Update:** Edit the details of an existing item.
- **Delete:** Remove an item from the list.
- **REST API Integration:** Perform CRUD operations using HTTP methods.
- **Interactive User Interface:** A clean and responsive interface built using HTML, CSS, and JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- REST API

## ⚙️ Installation and Setup

### Prerequisites

- Node.js installed on your system.
- A code editor such as Visual Studio Code.
- A web browser.

### Steps to Run the Project

**1. Clone the repository**

```bash
git clone https://github.com/Ashwini732/mern-lab-task-1-crud.git
```

**2. Navigate to the project directory**

```bash
cd mern-lab-task-1-crud
```

**3. Install the dependencies**

```bash
npm install
```

**4. Start the server**

```bash
node server.js
```

**5. Open the application**

Open your browser and visit:

```text
http://localhost:3000
```

The application is now ready to use.
